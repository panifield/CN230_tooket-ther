## 2. Authentication & Security (Phase 2)
- **JWT Implementation:** การใช้ `PyJWT` มีการกำหนด `exp` และ `iat` ครบถ้วน ทำให้ tokens มีความปลอดภัยเบื้องต้น
- **OAuth Flow:** รองรับทั้ง Line และ Facebook พร้อม Logic ในการสร้าง/อัปเดต user ข้ามแพลตฟอร์ม (Solid)
- **Dependency Injection:** `get_current_user` ใน `deps.py` ทำงานได้ถูกต้อง ตรวจสอบ JWT และโหลดข้อมูล Profile ลงใน request object ทันที

> [!WARNING]
> **Password Security:** ปัจจุบัน `_hash_password` ใน `auth.py` ใช้ SHA-256 แบบไม่มี Salt (ตามที่โน้ตไว้ในคอมเมนต์ว่าเป็น dev) สำหรับ Production **ต้องเปลี่ยนไปใช้ `bcrypt` หรือ `argon2`** เพื่อป้องกัน Rainbow Table attacks
